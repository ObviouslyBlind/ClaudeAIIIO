# Two Harbors

Two Harbors is a PAPER / SIMULATED harbour MMO shard. No wallet.

One shard. The sim owns cash, plots, staff, and prices. The browser is a camera. Live sockets and Postgres are not in yet.

```bash
cd game
npm install
npm test
npm run play
npm run play:laptop   # pasteable https link
```

South spawn. Left-click walks. Click a **$ tag** to buy. Lots overlay: click the lot dirt. Taxi on paved. Ferry $15. Restarting play wipes.
