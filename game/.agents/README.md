# Agent skills (game package)

Cursor loads `game/.agents/skills/` when working under `game/`.

These are **vendor** packs installed 2026-08-18 for harbour graphics, audio, QA, and Postgres notes. They are not a license to replace Two Harbors.

**Always read** `.cursor/skills/two-harbors-director/SKILL.md` first.

Do not install Godot / Unity / Unreal / Roblox / Phaser / OSM / Colyseus packs here.

Lockfile: `game/skills-lock.json`. Reinstall with `npx skills experimental_install` from `game/`.
