# Agent skills (game package)

Cursor loads `game/.agents/skills/` when working under `game/`.

These are **vendor** packs for harbour graphics, audio, QA, and Postgres notes.
They are not a license to replace Two Harbors.

**Grab:** `.cursor/skills/two-harbors-job-index/SKILL.md`  
**Always read** `.cursor/skills/two-harbors-director/SKILL.md` first.

Do not install Godot / Unity / Unreal / Roblox / Phaser / OSM / Colyseus / R3F packs here.

Lockfile: `game/skills-lock.json`. Research: `RESEARCH.md`.
Reinstall with `npx skills experimental_install` from `game/`.
