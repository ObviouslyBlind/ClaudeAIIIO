# Map templates

North and South island folders go here. Format is in `game/BACKEND.md`, `game/LAND.md`, and the `two-harbors-map` skill. Doc map: [`../../docs/README.md`](../../docs/README.md).

Coordinates are **metres**, origin at the channel. Do not drop OSM extracts in this directory.

`plots.json` is generated from `src/land.ts` (`npm run dump-plots`).
