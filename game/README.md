# 2Isles

PAPER / SIMULATED harbour MMO. One shard. The sim owns cash, plots, staff, and prices. The browser is a camera. No wallet. No live trading.

**Mid-alpha.** The harbour loop is the base. Features go on top of it. Politics (House / Senate / councils / elections) stay frozen until that loop is honest.

## Play

```bash
cd game
npm install
npm test
npm run play
npm run play:laptop   # pasteable https URL
```

South spawn. Left-click walks. **Lots** chip shows outlines. **$** bar opens a buy ask. Taxi on paved. Ferry $15. **Alpha wipe:** spawn / hard-refresh / play restart wipes this visitor. Restore is refused.
